# F00 shared contracts

This crate defines transport-neutral API types in `core` and a `Coordination` trait. MCP and CLI adapters pass an authenticated `SessionContext`; callers cannot choose authority via a mutation input. Session identity and role must be loaded from the coordinator's credential/session store for every request. Operations that mutate state take an idempotency key and return the canonical result plus the event ID. Reusing a key within `(session_id, operation, key)` with the same canonical request returns the original result/event and `replayed=true`; a different request is `IdempotencyConflict`. The persistence implementation must write state, event, and idempotency result atomically.

Events use schema version 1, UUID event identity, UTC timestamp, actor identity and role, optional project/run/task scope, stable snake-case event type, and structured JSON payload. Pagination is bounded and cursors are opaque, exclusive event IDs: subsequent pages contain strictly later records in durable event order; an unknown cursor is an error. MCP uses namespace `tesselate.v1`, schema version 1, `ToolRequest`/`ToolResponse`, and structured `{code,message,retryable}` errors. The initial exact tool names are exported as `mcp::TOOLS`. Request `params` are tool-specific JSON; the authenticated context is derived by the adapter from the validated credential and is never accepted from those params. The core API and data types do not depend on MCP.

Credential bootstrap, Git crash recovery, and completion semantics are decided in ADR-0001 through ADR-0003. F01–F11 should implement against these contracts. This is interface scaffolding; feature behavior remains with its feature owner.
